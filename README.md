# Rana AI

Rana AI is an Android assistant starter app with a Bengali chat screen, speech-to-text input, and text-to-speech replies.

## Build
Push to GitHub or run the **Build Rana AI APK** workflow from the Actions tab. Download the APK from the workflow run's Artifacts section.

## Current scope
This first build is a working starter shell. It does not yet connect to a generative AI service; full AI answers require a secure backend and an API credential. Do not put private API keys in the Android app.
